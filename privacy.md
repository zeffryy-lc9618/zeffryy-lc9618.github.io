# Privacy Policy — ComTask Private Backup

**Last updated: 10 November 2026**

## 1. About This Application

ComTask Private Backup is a personal backup utility used by its owner to securely back up application data to the owner's personal Google Drive account.

## 2. Google Drive Access

The application uses the Google Drive API with the `drive.file` permission.

This permission allows the application to manage Google Drive files created or specifically authorized for use with the application.

The application does not require unrestricted access to the owner's entire Google Drive.

## 3. Data Storage and Encryption

Backup archives may contain application database records, task information, messages, and private evidence files.

Backup content and file names are encrypted locally using rclone crypt before being uploaded to Google Drive.

The application does not intentionally publish backup data for public access.

## 4. Use and Sharing of Data

Google Drive access is used solely for backup storage, verification, retrieval, and disaster recovery.

The application does not sell Google user data or use it for advertising.

Google Drive acts as the storage provider under its applicable terms and privacy policies.

## 5. Data Retention and Deletion

Backup files are retained according to the owner's backup and retention settings.

The owner may delete backup files from Google Drive and revoke the application's access through Google Account security settings.

## 6. Security

The application uses OAuth authorization and local credential protection. Encryption credentials are kept separately from cloud backup archives.

No security system can guarantee absolute protection, but the application is designed to minimize unnecessary access to personal data.

## 7. Contact

For questions about this application or its data practices, contact the application owner using the support email displayed on the Google OAuth consent screen.
